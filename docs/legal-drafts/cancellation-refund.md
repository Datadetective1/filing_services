# Cancellation and refunds: additions (DRAFT)

**Draft for professional review. Not published.**

## Registered agent service

- **Before service starts.** If you cancel before the appointment is confirmed, we refund what
  you paid, less any state fee already paid to the state.
- **After service starts.** The yearly fee covers a full year of service and is not refunded
  for the unused part, except where the law requires it or we could not provide the service.
- **Turning off renewal** stops future charges. It does not end the current year early.
- **State fees** for a change of agent are refunded only if the change was not filed.

## Registered agent + annual report plan

- The plan's yearly fee is not refunded once the annual report it includes has been filed.
- If we have not filed the included report and you cancel within the first [Reviewer: period],
  we refund the fee less the value of registered agent service already provided.

## Formation

- Same as annual reports: full refund before we submit; after submission the state keeps its
  fee, and our service fee is refunded only if we made an error or could not complete it.
